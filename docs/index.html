三、v1.1.0 → v2.0.0 逐项提升明细（含实现与验证证据）

能力项v1.1v2.0变化本轮实现怎么验证的为何没给满分
B 向量语义检索24+2512 维 hashing TF 向量 + 余弦相似度并入排序；新增可选远程 Embedding 后端（NEUROMEM_EMBED_*，OpenAI 兼容），调用失败静默回退基准同义改写 19/19 命中；v2 检索 P50 572.7ms（v1 651.3ms）未做 ANN 索引，语义仍是词形哈希而非真语义嵌入，规模上万后会退化 → 4 分
C 关键词/倒排检索45+1真实 BM25：idf + 词频饱和(k1=1.5,b=0.75) + 文档长度归一，与倒排索引共用同一 df 统计基准 6 类场景含数字/配置/专名精确检索 19/19 命中已属标准 BM25 实现 → 满分
D 知识图谱/关系34+1新增 graph 子命令：实体节点 + 共现关系边 + 邻居查询，add/capture/correct/evolve 增量维护图谱实测 8 节点 3 边；--entity 查邻居通过专项用例关系无类型标注、无多跳推理与时间维度 → 4 分
M 自动捕获 Hook14+3新增 capture 子命令：按句→逗号拆分 + 信号打分（偏好/决策/数字/专名，≥2 分入选）+ 去重，规则引擎无需 LLM三事实对话捕获 3/3 条；单句长文本也能正确拆分需上层把对话文本显式交给 capture，不是生命周期钩子自动注入 → 4 分
N 离线巩固45+1consolidate 新增 --daemon/--interval-min/--busy-window：定时巩固 + 忙时退避（窗口内有写入则顺延）守护模式启动输出正常，timeout 124 证明循环在跑；忙退避读取 audit.jsonl 判定已有后台守护且带退避，达标杆 → 满分
O 可视化面板14+3serve 新增 GET /ui 内嵌面板（时间线/分层分布/缓存命中/图谱）+ GET /api/ui/statsHTTP 200，页面含标题，API 返回 total/active/cache/timeline/graph 全字段只读展示，无在线编辑与检索调参 → 4 分
P 接入方式45+1CLI 25 命令 + 本地 HTTP API + 新增 MCP stdio 服务器（initialize/tools.list/tools.call/ping）MCP 实测：initialize 握手 → memory_add 写入 → memory_search 命中三种接入齐全，达标杆 → 满分
R 自主进化14+3新增 evolve 子命令：按主题实体聚类纠偏历史，同主题 ≥2 次自动合成 procedural 规则记忆并留审计两次同主题纠偏后 evolve 生成 1 条规则（张三）只从纠偏历史学习，未覆盖任务失败/工具调用错误的泛化学习 → 4 分
S 反馈闭环24+2correct 沉淀 correction_rules（topic/old/new），检索时规则参与排序：纠偏后表述 ×1.15、同主题旧表述 ×0.60，两条检索路径（打分/宽泛兜底）均生效实测：纠偏后新表述 0.9775 排第一，再次入库的旧说法 0.51 排后；专项用例「纠正后旧说法不再排前」通过无显式 👍/👎 反馈入口与效果回归度量 → 4 分
T 公开基准03+3新增 benchmark 子命令：内置 19 组评测（语义改写/偏好身份/数字配置/项目业务/数值矛盾/时间线矛盾）实测 accuracy 100%、recall 100%、avg_query_ms 33.48，可一键复现是自建合成集，未跑 LoCoMo/LongMemEval 等公共基准，无第三方可比分数 → 3 分
K 端侧加密44±0加密升级 enc:v2：scrypt 派生密钥 + HMAC-SHA256 认证（encrypt-then-MAC），兼容 enc:v1篡改 1 字节后 get 返回 integrity check failed；正常解密通过可检出篡改，但构造为自研（32 字节周期密钥流），非 AES-GCM/ChaCha20-Poly1305 标准 AEAD，未经密码学审计 → 仍 4 分

内置基准（benchmark）

评测集：19 组查询 / 6 类场景（语义改写、偏好身份、数字配置、项目业务、数值矛盾、时间线矛盾）

口径已修正：avg_query_ms 只统计检索，不再把写入耗时算进去。

性能对比（200 条记忆，30 次查询）

v1.1.0：avg 674.9 ms / p50 651.3 / p95 822.1（含解释器启动）

v2.0.0：avg 573.3 ms / p50 572.7 / p95 675.5 → 快 15.1%

结论：加入向量+BM25 未带来延迟代价，反而因召回路径收敛更快。

安全与正确性专项

加密：密文篡改 1 字节 → integrity check failed；正常解密不受影响；兼容 enc:v1 存量

反馈闭环：纠偏后新表述得分 0.9775 排第一，再次入库的旧说法被压到 0.51

MCP：initialize → tools/list → memory_add → memory_search 全链路通
