## ✨ 它是什么

一套模拟人脑记忆机制的通用记忆系统，供 AI 助手跨会话、跨应用记住用户信息。核心思路是"像人一样记东西"：

### 三层记忆 + 遗忘曲线

```
工作记忆（瞬时） ──► 短时记忆 ──► 长时永久记忆
        │                │              │
     会话上下文      默认写入层      高频/高重要性
                    半衰期 14 天     半衰期 60 天
```

按 **重要性 × 访问频次 × 时效衰减** 自动迁移，配合遗忘曲线模拟"不用就淡忘"——但归档永不物理删除，随时可唤醒。

### 三路混合召回

```
sem   = max(字面bigram相似度, 标签相似度, 实体相似度)
vec   = cos(512维哈希TF向量)        → 换个说法也能撞上
bm25  = Σ idf · tf饱和 · 长度归一化  → 关键词精确命中
```

三路互补：字面管"原话复述"，向量管"换个说法"，BM25 管"关键词命中且长文档不算亏"。三者量纲统一后加权，单路失效不会整体崩塌。

### 纠偏一次，同类不再犯

```
correct(旧 → 新)
  ├─► 旧记忆失效 + 版本快照（可回溯）
  ├─► 新记忆建立纠偏链
  ├─► 失效相关缓存（防脏缓存）
  └─► 沉淀纠偏规则 → 后续同主题检索：新表述加权、旧表述降权
              └─► 同主题纠偏达阈值 → 合成程序性规则记忆
```

### 语义缓存直接省 Token

回答前先查缓存：热（精确命中）→ 温（语义相近）→ 冷（模糊匹配），命中即返回，**完全不调用大模型**。

### 认证加密

密文采用 encrypt-then-MAC 构造，先验后解：改任意 1 字节即报完整性校验失败；密钥错误与密文篡改返回同一错误，不泄露区分信息。
