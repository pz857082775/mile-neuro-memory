## 二、短板逐项对照：5 分标杆的表现与达标标准

### S1 · T 公开基准跑分（0 → 5）
- **标杆表现**：Mem0 在 LoCoMo 92.5 / LongMemEval 94.4；MindMemOS LoCoMo 94.03（SOTA）；agentmemory LongMemEval-S R@5=95.2%。均有公开评测脚本与论文背书。
- **达标标准（5 分）**：接入 LoCoMo / LongMemEval 至少一个公开评测集，跑通本地脚本并产出可复现数据（准确率/召回率数值）；数据写入 README 与技能说明；能对版本迭代做回归对比。
- **涉及环节**：长期记忆管理（效果度量闭环）。

### S2 · M 自动捕获 Hook（1 → 5）
- **标杆表现**：agentmemory 通过 12 个生命周期钩子（写代码/跑测试/修 bug）自动捕获并压缩为记忆，零手动操作；OpenClaw Memory Upgrade 用 memoryFlush 在上下文临近压缩时自动落盘八类信息。
- **达标标准（5 分）**：提供会话级监听/钩子接口（无需改上层业务逻辑，传会话消息列表即可）：对话结束自动执行"关键事实提取→写入短时记忆→过滤无关内容"；同一会话多次运行时去重；误沉淀率可调（阈值/开关）。
- **涉及环节**：上下文理解（从对话中"看到"值得记的信息）。

### S3 · R 自主进化（1 → 5）
- **标杆表现**：MemSkill 用控制器-执行器-设计器闭环，从失败案例自动改进/新增记忆技能（LoCoMo +10~15pp）；MindMemOS MindEvolve 从真实执行轨迹提炼成功策略（任务成功率 51.3%→57.2%）。
- **达标标准（5 分）**：存在"失败案例缓冲→模式归纳→规则沉淀进程序记忆库（procedural）→后续检索自动引用"的闭环；规则带版本与来源可回溯；规则数量与命中率可统计。
- **涉及环节**：长期记忆管理（越用越聪明）。

### S4 · O 可视化面板（1 → 5）
- **标杆表现**：ReMe Studio 浏览器可视化浏览/编辑记忆文件与记忆图；agentmemory 实时 Viewer（端口 3113）+ Session Replay 时间轴。
- **达标标准（5 分）**：`serve` 模式内置 Web UI：记忆时间线、知识图谱视图、缓存命中/Token 节省看板、单条记忆的查看/修正/删除操作；只读 API 已完成，UI 可复用。
- **涉及环节**：人机交互体验（看得见、管得着）。

### S5 · B 向量语义检索（2 → 5）
- **标杆表现**：Mem0/agentmemory 多信号融合（语义向量+BM25+实体，RRF 融合）；JiuwenMemory 向量+图谱双路。无 Embedding 场景退化为关键词。
- **达标标准（5 分）**：`search` 支持可选 Embedding 后端（本地/远程模型，API Key 可配）；向量+关键词多路召回融合排序；无 Embedding 时自动回退现有 bigram（保底不坏）；接入后 1000 条库检索延迟仍 ≤30ms（可用缓存/截断控制）。
- **涉及环节**：召回（搜得准）。

### S6 · S 反馈闭环（2 → 5）
- **标杆表现**：MindMemOS Feedback 兼容显式+隐式反馈，自动识别信号类型并执行"新增/更新/归档/删除/权重强化"。
- **达标标准（5 分）**：用户 `correct` 或否定表述（不喜欢/不是/错了）后，系统自动：①关联旧记忆标 pending/invalid；②降低该类内容的检索权重；③沉淀一条"纠偏规则"；后续同类错误不再复现（可复测）。
- **涉及环节**：上下文理解 + 长期记忆管理（减少混淆）。

### S7 · D 知识图谱/关系（3 → 5）
- **标杆表现**：MindMemOS 实体-属性-时间三维图（追踪演变）；JiuwenMemory GraphMemory 实体/关系/Episode 溯源，支持多跳召回。
- **达标标准（5 分）**：记忆写入时自动抽取实体与关系（可与 LLM 提炼位共用）；图谱支持实体节点+属性+时间线（同一实体最新状态与历史并存）；检索支持沿关系 1~2 跳扩展；图谱数据可导出可视化。
- **涉及环节**：召回（联想扩展由"像"升级为"相关"）。

### S8 · C 关键词检索（4 → 5）
- **标杆表现**：agentmemory/Mem0 用 BM25 打分 + RRF 融合，命中质量高于纯计数。
- **达标标准（5 分）**：倒排命中由"计数"升级为"BM25 打分"（标准库可实现近似）；与语义分加权融合；长查询/口语查询质量不劣化。
- **涉及环节**：召回。

### S9 · K 端侧加密（4 → 5）
- **标杆表现**：行业标准为 AEAD（AES-256-GCM）+ 密钥派生（scrypt/Argon2）+ 防篡改（认证标签）。
- **达标标准（5 分）**：加密从 XOR 流升级为标准 AEAD（密文+随机 nonce+认证标签，篡改可检出）；向后兼容旧 enc:v1 格式（解密旧数据）；密钥不落盘或受系统保护。
- **涉及环节**：安全隔离（数据安全不裸奔）。

### S10 · N 离线巩固（4 → 5）
- **标杆表现**：JiuwenMemory AutoDreaming 后台守护进程（浅睡/REM/深睡三阶段、忙碌退避、断点续扫）；MindMemOS Dreaming 静默整理。
- **达标标准（5 分）**：提供可选后台调度（守护线程/cron 均可）：低峰期自动跑 consolidate；忙时退避；日志完整；不影响前台读写（独立进程或锁）。
- **涉及环节**：长期记忆管理（自动整理）。

### S11 · P 接入方式（4 → 5）
- **标杆表现**：Mem0/Cognee 原生 MCP server，Claude Code/Cursor 即插即用。
- **达标标准（5 分）**：新增 `mcp` 子命令（stdio 协议）：暴露 add/search/get/correct/cache/stats 等核心工具；任意 MCP 客户端（如 Claude Code）可直连调用。
- **涉及环节**：工程化接入（生态打通）。

## 四、分阶段实施计划

### 阶段一（P0 组，约 2~3 周）——"搜得准、记得上、通得开"
- **实施内容**：RQ-01 → RQ-02 → RQ-03 → RQ-04 → RQ-05（顺序：先检索质量，再自动捕获，后生态接入）。
- **回归保障**：每完成一项跑一遍 63 项自动化测试（`nmem-tests/test_neuromem.py`），确保满分 9 项不回退。
- **预期收益**：
  - 评分 71 → 约 82（B 2→5、C 4→5、M 1→5、P 4→5、D 3→5）
  - 用户可感知：换一种说法也能找到记忆；关键信息免手动保存；Claude/Cursor 可直接对接
  - 风险与取舍：向量检索增加依赖（Embedding 服务/模型）——以"可选后端+自动回退"控制，保零依赖底线

### 阶段二（P1 组，约 2 周）——"越用越对、看得见"
- **实施内容**：RQ-06 → RQ-07 → RQ-09 → RQ-08（先做纠错闭环，再做可视化）。
- **回归保障**：同上 + 新增反馈/进化场景测试用例。
- **预期收益**：
  - 评分 82 → 约 90（S 2→5、R 1→5、N 4→5、O 1→5）
  - 用户可感知：纠正过一次的错误不再犯；记忆自动整理；可以打开网页管理自己的记忆
  - 风险与取舍：进化闭环涉及 LLM 复盘（若无可降级为规则化复盘，保证离线可用）

### 阶段三（P2 组，约 1 周，可按需裁剪）——"更安全、有背书"
- **实施内容**：RQ-10 → RQ-11。
- **预期收益**：加密达到主流标准；拥有公开基准成绩，便于开源社区传播与信任建立。
- **取舍说明**：跑分脚本投入不小且评测集需自行下载，若优先社区传播可把 RQ-11 提前；若时间紧可先做 RQ-10。

## 六、依赖与风险

| 项 | 说明 |
|----|------|
| 零依赖底线 | 所有新增能力必须"可选增强"：无 Embedding/无 LLM/无 MCP 客户端时，现有功能不退化（自动回退 bigram / 规则化复盘 / 仅 CLI） |
| Embedding 后端 | 沙箱无外网，采用"先抽象接口+远程 API 配置位"，本地模型位预留；验收以 mock 后端 + 回退路径为准 |
| 兼容性 | v2.0 需向后兼容 v1.1.0 存量数据（enc:v1 旧密文、旧索引可重建） |
| 测试保障 | 63 项基线测试为门禁，新增用例随阶段补充，禁止先破坏后修复 |
